# Bank-portal-with-AI-chat-board

 # Project Overview

BankBot AI is an AI-based chatbot developed to automatically answer common banking questions.
Banks receive many repetitive queries from customers, which increases workload and response time. This chatbot helps solve that problem by providing instant and automated responses using Natural Language Processing (NLP).

The system understands user queries and responds with relevant banking information without human intervention.

# Problem Statement

Banks face several challenges such as:

Large number of repetitive customer queries

Delay in response time

High workload for customer support staff

Customers expecting 24/7 support

# Proposed Solution

BankBot AI provides an intelligent chatbot system that:

Understands banking-related questions

Uses NLP techniques to interpret user intent

Responds instantly with accurate answers

Works anytime without human support

# Project Features
1. Intent and Entity Recognition

Identifies user intentions such as:

Balance enquiry

Loan related queries

Debit/credit card services

Banking FAQs

Uses SpaCy NLP model for understanding user queries.

# Extracts entities like:

Account type

Loan type

Card category

2. Dialogue Management

Handles conversation flow using rule-based logic.

Supports follow-up questions.

Provides fallback responses for unknown inputs.
